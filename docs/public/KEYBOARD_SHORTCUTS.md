# Keyboard Shortcuts

Shortcut reference for the current source. See the [documentation release status](index.md) for differences from the packaged release.

**Last updated:** 2026-09-08

---

## Global Shortcuts

These work system-wide, even when Beetroot is hidden.

| Shortcut              | Action                                                  |     Customizable     |
| --------------------- | ------------------------------------------------------- | :------------------: |
| **Ctrl+`** (backtick) | Show / hide Beetroot                                    |         Yes          |
| Plain text hotkey     | Paste clipboard as plain text, stripping all formatting | Yes (off by default) |

> Both global shortcuts can be changed in Settings > Shortcuts.

> **No-focus mode:** Normal and follow-cursor hotkey openings can preserve the original app's focus for list navigation. Click search to activate Beetroot before typing. Pasting requires the original target to remain available; otherwise you get copy-only feedback. Pinned mode copies instead of automatically pasting.

## Main Window

These shortcuts apply while the popup/list is active. In particular, Ctrl+1 through Ctrl+9 are not global shortcuts while Beetroot is hidden; they do not select clips while typing in search.

| Shortcut                     | Action                                                                              |
| ---------------------------- | ----------------------------------------------------------------------------------- |
| Arrow Up / Arrow Down        | Navigate the clip list                                                              |
| Home                         | Jump to first clip                                                                  |
| End                          | Jump to last clip                                                                   |
| Page Up / Page Down          | Jump 10 clips up / down                                                             |
| Enter                        | Paste the selected clip (or copy, if in pinned or copy-only mode)                   |
| Space                        | Toggle preview for the selected clip (open and close; when the search bar is empty) |
| Escape                       | Hide the Beetroot window                                                            |
| Ctrl+1 through Ctrl+9        | Quick-paste the 1st through 9th clip                                                |
| Ctrl+C                       | Copy the selected clip to clipboard without pasting                                 |
| Alt+S                        | Star / unstar the selected clip                                                     |
| Alt+T                        | Toggle the Transform menu for the selected clip (open and close)                    |
| Alt+Delete                   | Delete the selected clip                                                            |
| Ctrl+Space                   | Toggle multi-select on the current clip                                             |
| Ctrl+Click                   | Toggle multi-select on the clicked clip                                             |
| Right-click                  | Open the context menu                                                               |
| Shift+F10 or ContextMenu key | Open the context menu for the selected clip (keyboard)                              |
| Alt+P                        | Pin / unpin the window (customizable)                                               |
| Alt+F                        | Toggle follow-cursor mode (customizable)                                            |

## Search Bar

| Shortcut                | Action                                      |
| ----------------------- | ------------------------------------------- |
| Click search, then type | Activate the search field and enter a query |
| Click the `.*` button   | Toggle regex search mode                    |
| Click the X button      | Clear the search and show all clips         |

---

## Filter Bar

| Shortcut                 | Action                      |
| ------------------------ | --------------------------- |
| Arrow Left / Arrow Right | Switch between filter chips |
| Home / End               | Jump to first / last filter |

---

## Preview Panel

| Shortcut              | Action                                                       |
| --------------------- | ------------------------------------------------------------ |
| Arrow Up / Arrow Down | Navigate to the previous / next clip without closing preview |
| Space or Escape       | Close preview                                                |
| Ctrl+C                | Copy the content to clipboard                                |
| Enter (in note field) | Save note and close the note field                           |

---

## Transform Menu

| Shortcut | Action                   |
| -------- | ------------------------ |
| Escape   | Close the Transform menu |

---

## Context Menu

| Shortcut              | Action                          |
| --------------------- | ------------------------------- |
| Arrow Up / Arrow Down | Navigate menu items             |
| Enter or Space        | Activate the highlighted option |
| Escape                | Close the menu                  |
