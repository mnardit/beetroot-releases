## Установка

**[Скачайте последнюю версию .exe из GitHub Releases](https://github.com/mnardit/beetroot-releases/releases/latest)** или установите из **[Microsoft Store](https://apps.microsoft.com/detail/9ng50mkds58x)**.

Или через пакетный менеджер:

```powershell
# Winget
winget install MNardit.Beetroot

# Scoop
scoop bucket add beetroot https://github.com/mnardit/scoop-bucket
scoop install beetroot

# Chocolatey
choco install beetroot
```

**Требования:** Windows 10 или новее.

## Возможности

### Поиск и рабочий процесс

- **5-фазный поиск** — точная подстрока → начало слова → метаданные → нечёткий. Толерантен к опечаткам с ранжированием результатов
- **Режим регулярных выражений** — `/pattern/` с подсветкой совпадений
- **Фильтры** — текст, изображения, избранное, заметки — один клик для фильтрации
- **Быстрая вставка**: `Ctrl+1..9` выбирает недавний клип при активном списке Beetroot; при скрытом окне это не глобальный хоткей.
- **Групповые операции** — множественный выбор через `Ctrl+Click`, затем копирование (свой разделитель) или удаление
- **Детекция контента** — автобейджи для URL, email, кода, JSON, цветов. ML-детекция языков программирования (54 языка) для предпросмотра кода
- **Один экземпляр** — повторный запуск Beetroot фокусирует существующее окно

### AI-трансформации

- **4 облачных провайдера + локальный** — OpenAI, Gemini, Claude, DeepSeek или локальный (LM Studio, Ollama), переключение в один клик
- **Фоновая обработка** — нажмите на промпт, меню закроется мгновенно, уведомление когда готово. Очередь нескольких трансформаций
- **Reasoning-модели** — Qwen3, DeepSeek R1 и аналогичные работают из коробки (автоматически убирает теги `<think>`)
- **10 текстовых промптов** — исправление грамматики, перевод, пересказ, переписывание, извлечение данных, форматирование кода и другое
- **Свои промпты** — до 20 своих, доступны из контекстного меню
- **BYOK** — используйте свой ключ OpenAI, или обойдитесь без него с локальной моделью
- **Нативный Rust** — все AI API-вызовы выполняются в нативном коде, а не в браузере. Без проблем с CORS, работает когда окно скрыто

### AI Vision

- **5 встроенных vision-промптов** — Прочитать текст, Описать изображение, Извлечь данные, Краткое содержание, Перевести текст
- **Работает с любым изображением в истории** — скриншоты, фото, сканы, рукописные заметки
- **Облако + локально** — GPT-5.4, Claude, Gemini или локальные модели (Ollama llava/bakllava/moondream, LM Studio)
- **Пользовательские vision-промпты** — создавайте свои в Настройки → AI → тип «Изображение»
- **Примеры использования:** распознавание рукописных рецептов, извлечение данных из чеков, OCR скриншотов на иностранных языках, описание диаграмм

### Отслеживание приложений-источников

- **Видно откуда каждый клип** — иконка приложения, название и заголовок окна
- **Фильтр по приложению** — выпадающий список «Приложения» с поиском, сортировка по последнему / частому / алфавиту
- **Поиск** — приложение-источник и заголовок окна участвуют в нечётком и regex-поиске

### OCR

- **Извлечение текста из изображений** — правый клик по изображению → OCR
- **Нативный движок Windows** — без облака, без загрузок, полностью офлайн
- **Мгновенно** — работает асинхронно, не тормозит интерфейс

### Кастомизация

- **9 тем** — Beetroot Dark/Light, Tokyo Night Storm, Gruvbox, GitHub Light, Nord Snow, Cyberpunk Dark/Light, Pure Dark (OLED #000000), плюс Авто-режим
- **Эффекты окна** — Mica, Acrylic или Solid; определяются автоматически по версии Windows
- **Типографика** — 8 UI-шрифтов, 5 шрифтов для кода, 6 размеров
- **26 языков** — EN, RU, DE, ES, ZH, JA, FR, PT, KO, TR, IT, PL, NL, UK, TH, HI, ID, VI, CS, HU, RO, SV, DA, FI, NB, MS
- **Закрепление окна** — поверх всех окон, перетаскивание между мониторами, режим следования за курсором
- **Все хоткеи настраиваются** — переназначьте всё в Настройки → Горячие клавиши; поддержка AZERTY, QWERTZ, AltGr

### Надёжность

- **Бэкапы базы данных**: до 3 копий с ротацией и снимок перед миграцией базы. Изображения и настройки требуют отдельного бэкапа.
- **Восстановление с уведомлением**: при возможности восстанавливает повреждённую базу из исправной копии, сохранив оригинал; последние записи могут отсутствовать.
- **Предупреждения об облачной синхронизации** — если папка данных внутри OneDrive, Dropbox или Google Drive
- **Проверка диска**: предупреждает о съёмных дисках и облачных папках; сетевые диски для базы данных запрещены.
- **Автообновление** — встроенный апдейтер, можно отключить для полностью офлайн работы

## Горячие клавиши

| Сочетание    | Действие                     |
| ------------ | ---------------------------- |
| `` Ctrl+` `` | Показать / скрыть Beetroot   |
| `Enter`      | Вставить выбранный клип      |
| `Ctrl+1..9`  | Быстрая вставка              |
| `Space`      | Предпросмотр                 |
| `Alt+T`      | Трансформация AI             |
| `Alt+P`      | Закрепить окно поверх        |
| `Alt+F`      | Режим следования за курсором |
| `Shift+F10`  | Контекстное меню             |

Все горячие клавиши настраиваются в **Настройки → Горячие клавиши**. Работает с AZERTY, QWERTZ и AltGr раскладками.

## FAQ

**Beetroot бесплатный?**
Да. Бесплатен для личного и коммерческого использования — без рекламы, пробных периодов, ограничений функций и телеметрии.

**Beetroot отправляет данные буфера обмена куда-то?**
История хранится локально. Облачный AI получает только выбранный контент и промпт по вашему запросу на трансформацию. Локальный AI использует loopback-сервер; его собственные логи и сетевые обращения зависят от настроек. Обновления и проверка ключей тоже выполняют сетевые запросы. Подробнее в [PRIVACY.md](PRIVACY.md).

**Может ли Beetroot читать текст с изображений?**
Да. Правый клик на изображение → AI → Прочитать текст. Работает с облачными (GPT-5.4, Claude, Gemini) и локальными моделями. Для простого OCR без AI есть встроенный OCR (Windows-движок, полностью офлайн).

**Работает ли AI Vision офлайн?**
Да, с заранее скачанной моделью на локальном сервере. Beetroot обращается к нему через loopback; офлайн-работу самого сервера проверьте в его настройках.

**Где хранится API-ключ?**
В диспетчере учётных данных Windows (Windows Credential Manager), отдельно от настроек приложения. Ключ передаётся выбранному AI-провайдеру при выполнении AI-операции или проверке сохранённого ключа. Подробности миграции ключей из старых версий описаны в [PRIVACY.md](PRIVACY.md).

**Где хранятся данные?**
По умолчанию в `%APPDATA%\com.beetroot.desktop\`; выбранная папка указана в Настройки > Данные. Перед копированием всей папки для бэкапа истории завершите Beetroot через трей. Настройки и API-ключи хранятся отдельно. См. [инструкцию резервного копирования](PRIVACY.md#exporting-clipboard-history).

**Работает ли автообновление?**
Да, начиная с v1.0.6. Пользователям v1.0.5 и раньше нужно [скачать вручную](https://github.com/mnardit/beetroot-releases/releases/latest) один раз — после этого автообновление работает нормально. Автообновление можно отключить в Настройки → Основные.

## Решение проблем

**Автообновление не работает (v1.0.5 и раньше)**
Одноразовая смена ключа подписи требует [скачать последнюю версию вручную](https://github.com/mnardit/beetroot-releases/releases/latest). Будущие обновления будут работать автоматически.

**OCR не работает или низкое качество**
OCR использует нативный движок Windows. Убедитесь, что нужный языковой пакет установлен: Параметры → Время и язык → Язык → Добавить язык → отметьте «Речь» или «Базовый ввод».

**Beetroot не открывается или хоткей не работает**

- Проверьте, не занят ли хоткей другим приложением (например, `Ctrl+``)
- Проверьте, что Beetroot работает в том же сеансе Windows, что и целевое приложение; обычный процесс не может отправлять ввод в приложение с повышенными правами.
- Переназначьте хоткей в Настройки → Горячие клавиши

**Предупреждение SmartScreen или антивируса**
Windows может показать SmartScreen для установщика без устоявшейся репутации издателя. Скачивайте с [официальной страницы релизов](https://github.com/mnardit/beetroot-releases/releases/latest) и проверяйте происхождение файла перед запуском. Подпись обновлений Tauri и Windows Authenticode являются разными механизмами.
